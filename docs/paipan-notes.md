# 排盘口径说明

本引擎在几个存在流派/口径分歧的位置所做的选择,以及对应的配置开关。

## 年柱与生肖:双口径

- **年柱**以**立春精确时刻**为界(子平法标准,由 tyme4ts 计算,秒级)。
- **生肖**以**农历正月初一(春节)**为界(民俗主流口径)。
- 因此**立春~春节之间**出生者,生肖与年支会"错位"(例:2024-02-05 出生,年柱已是甲辰,生肖仍属兔)。这是有意为之的双口径,不是 bug。

## 晚子时(23:00-24:00)日柱归属:可配置

- 默认 `lateZiRule: 'next-day'`——子初(23:00)换日,晚子时日柱算次日(现代排盘软件主流)。
- 可选 `lateZiRule: 'same-day'`——晚子时日柱算当天(传统子平一派),时柱天干仍按次日日干五鼠遁起子时。
- 两派的时柱完全一致,只有日柱差一位。已在差分测试中与 lunar-javascript 独立实现交叉验证。

## 时区:`utcOffset`(默认 8)

- 真太阳时模式的标准经线 = `utcOffset × 15°`。海外出生按当地钟表时间输入时必须设置(如美东冬令时 -5)。
- 中国夏令时(1986-1991)自动校正仅在 `utcOffset === 8` 时生效。
- 出生经度与标准经线相差超过 30°(2 小时)会输出预警,提示核对时区。

## 真太阳时精度

- 均时差采用 NOAA/Meeus 天文算法,1900-2100 精度约 ±数秒(旧版一阶近似式误差 ±1-2 分钟,可能在时辰边界翻柱)。
- 经度差按 `(经度 - 标准经线) × 4` 分钟。
- 校正后的完整时刻会**整盘重排**(含跨日、跨节气),并对距节气交接/时辰边界 ±3 分钟内的出生时刻输出两可预警。

## 中国夏令时(1986-1991)

- 六段精确区间(每年 4 月中旬 02:00 至 9 月中旬 02:00,首年 1986 自 5 月 4 日起)。
- 真太阳时模式(有精确时分)自动回拨 60 分钟;仅时辰精度时只提示不校正。
- 结束日 01:00-02:00 的重复时段、开始日 02:00-03:00 的跳变时段分别输出专门预警。
- 若所记时间已折算为标准时间,设 `applyChinaDst: false`。

## 日主强弱评分

- 框架:得令(旺相休囚死)+ 通根 + 帮扶 − 克泄耗,线性加总后按阈值分档。
- 克泄耗类别权重:官杀(基础+0.4)> 财 > 食伤;藏干基础权重减半,官杀 +0.4 固定加成不减半。
- **分档模型可选**(`Person.strengthModel`):
  - `legacy`(默认):原始阈值 6/4/2.5/1,保持既有行为。
  - `classic-calibrated`:按《滴天髓阐微》61 例任铁樵批语命例校准的阈值
    (身强≥2.5 / 偏强≥0 / 偏弱≤-1.5 / 身弱≤-2.5)。校准数据下三分类吻合度
    82%(legacy 67%);评分本身存在约 -4 分的系统性偏移,两模型评分一致、
    仅分档不同。校准工具:`scripts/calibrate-strength.mjs`,
    命例集:`tests/fixtures/strength-calibration-cases.json`(含原文引文可溯源)。

## 用神:四派决策框架(为什么不是"一派定论")

用神选取是命理体系最主观、分歧最大的一步——**排盘是死算,取用是流派活**。
古典各派对"这张盘最需要哪个五行"的定义不同,没有一派垄断真理。本引擎参考
[DeepOracle 四派决策框架](https://www.deeporacle.ai/bazi/blog/bazi-yongshen-decision-framework),
把四派各自的独立判读全部透出(`usefulGod.schools`),**而非只报一个结论**:

| 流派 | 命题 | 引擎字段 |
|---|---|---|
| **扶抑** | 身强泄身、身弱补身(最常用,可脚本化) | `schools.fuyi` |
| **调候** | 月令寒暖燥湿为先:冬木必火、夏火必水(《穷通宝鉴》) | `schools.tiaohou` |
| **病药** | 命局最尖锐矛盾为"病",用神是"药"(《子平真诠》) | `schools.bingyao` |
| **专旺** | 一行独旺则**顺势**(喜同党/印,忌克它),逆势招凶 | `schools.zhuanwang` |

**引擎的处理原则(与 DeepOracle 一致)**:

1. **不强行调和**:四派冲突时如实并列呈现,分歧来自方法论前提不同,不是谁算错。
   最终裁决仍按既定顺序(调候优先),但 `schools` 保留四派原始判读供解读层取舍。
2. **专旺显式阈值**:`zhuanwang.qualifies` = 旺神占比 ≥50% 且克/泄反力均 <10% 且旺神即日主;
   `nearMiss` = 旺神 ≥42% 但未达门槛(标记"扶抑vs专旺分歧高发盘")。
   门槛高是有意的——专旺格实际很罕见,宁可判 nearMiss 也不轻易成格。
3. **场景分发**:日常调和(颜色/穿搭/方位)以**调候**为主;重大决策以**扶抑+病药**为主;
   极端命局先看**专旺**。
4. **共识标记**:`schools.consensus` = 各适用派首选五行完全一致时给出的高信心五行,否则 null。

**示例(某甲木亥月、木旺近专旺之盘)**:木偏旺但有丙火透干泄秀,
`zhuanwang.nearMiss=true`(旺木未达门槛,泄力≥10%,不成专旺),扶抑/调候/病药三派
`consensus=火`。这类盘正是"民间按专旺读出忌火不戴金"与"主流三派喜火"结论相反的高发区——
分歧点是**这棵冬天的大树该修剪(扶抑)还是该顺着长(专旺)**,而按量化门槛此类盘不成专旺。

传播路径:`schools` 结构化字段 → `formatBaziForPrompt` 输出「用神四派」「四派共识/流派分歧」
两行 → 经 aiPrompts 流入 MCP `bazi_prompt`;看板排盘页有「用神四派对照」表。

## 支持年份范围

- **八字排盘**:公历 **1600-2100**(下限从 1900 放宽,支持古籍命例反查;
  1600 起避开 1582 儒略/格里历切换)。1900 前已用乾隆帝史载八字
  (1711-09-25,辛卯丁酉庚午丙子)做金标准校验,但未与万年历权威源逐日核对,谨慎使用。
- **紫微/黄历/占卜等其他域**:维持 1900-2100(底层 iztro 等依赖的支持范围)。

## 轻量 API

- `calculatePillars(person)`:只算四柱与基础信息(<1ms),适合批量校验与只需盘面的调用方。
- `calculateBazi(person)`:完整盘(含大运/流年/神煞/分析,约 45ms)。
